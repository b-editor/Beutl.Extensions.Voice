# Beutl.Extensions.Voice

Beutlにテキスト読み上げ機能を追加する拡張機能です。
VOICEVOXを使用しています。

## 声のプリセット

「テキスト読み上げ」タブで本文を入力し、話者・スタイルを選んで、下部の「試聴」「追加」を使います。細かい設定は「調声」、発音ごとの調整は「アクセント / ピッチ」から開きます。

プリセットには話者・スタイル、話速、音高、抑揚、音量、前後無音を保存できます。一覧から選んで「適用」で復元します。右の「…」メニューから保存・更新・複製・改名・削除と、保存値との差分の確認を行います。

- **全体**: Beutl のホームディレクトリ内の `voice/presets.json` に保存し、別のプロジェクトでも利用できます。
- **プロジェクト**: 保存済みの `.bep`（単独シーンの場合はシーンファイル）と同じ場所に、同名の `.voice-presets.json` として保存します。プロジェクトを移動するときはこのファイルも一緒に移動してください。

プリセットと話者は表示名ではなく ID で識別します。保存された声が見つからない場合は通知され、話者を選び直せます。現時点では内蔵 VOICEVOX Core の設定を扱います。

生成した読み上げ要素には、本文・話者・調声値・最終 AudioQuery とプリセットの識別情報を保存します。プリセットを更新・削除しても既存の音声と生成時設定は変わりません。

既存セリフへ変更を反映するには、タイムラインで読み上げ要素を選び、上部の「選択から読込」を押します。上部に編集対象の名前が表示され、下部の「追加」が「再生成」に切り替わります。情報ボタンから生成時設定を確認でき、「＋」で新しいセリフの追加に戻れます。追加・試聴と同じ合成処理を使い、音声と設定をまとめて Undo/Redo できます。配置・要素の長さ・トリム・エフェクトは保持するため、変更後の音声尺に合わせて必要に応じて要素の長さを調整してください。旧バージョンで作成した要素には生成時設定がないため、初回は話者を選択してください。

## 開発時の検証

```sh
dotnet test tests/Beutl.Extensions.Voice.Tests -c Release
```

`VOICE_TEST_CAPTURES` に出力先を指定すると Headless の画面画像を保存します。`VOICEVOX_TEST_HOME` に Core・辞書・モデルを導入済みのディレクトリを指定すると、実音声の生成・再生成・Undo/Redo も検証します。指定しない場合、この実音声テストだけをスキップします。
