# Beutl.Extensions.Voice

Beutlにテキスト読み上げ機能を追加する拡張機能です。
内蔵の VOICEVOX Core と、外部の VOICEVOX 互換 HTTP エンジンを使用できます。

「テキスト読み上げ」タブの上部で「読み上げ」「台本」「設定」を切り替えられます。読み上げと台本の入力は切り替えても保持され、タブの保存時にまとめて保存されます。

## エンジンの接続

VOICEVOX・AivisSpeech・SHAREVOXをインストール済みの場合は、上部の「設定」を開きます。初回の案内の「エンジンを探す…」やエンジンメニューからも移動できます。標準の接続先を確認し、「接続して追加」で登録できます。停止中のアプリは「起動して追加」、通常の配置場所で見つからないアプリや単体エンジンは「アプリを選択…」から指定できます。検索だけではアプリを起動しません。登録後も音声生成にはエンジンの起動が必要です。

ポートを変更している場合や別のPCのエンジンを使う場合は、外部エンジンを起動し、「テキスト読み上げ」タブの「エンジン」横の「…」から「接続先を追加…」を開きます。表示名と送信先URLを入力して「接続して保存」を押すと、話者・スタイルを選んで試聴・音声生成できます。接続先URLはエンジンの下にも表示されます。

接続先には任意の HTTP / HTTPS URL を指定できます。VOICEVOX ENGINE の通常のURLは `http://127.0.0.1:50021`、AivisSpeech Engine は `http://127.0.0.1:10101`、SHAREVOX ENGINE は `http://127.0.0.1:50025` です。VOICEVOX ENGINE 0.26.0 と AivisSpeech Engine 1.2.0 で生成・再生成・台本の一括生成を確認しています。SHAREVOXなど、話者一覧・AudioQuery・WAV合成のAPIが共通のエンジンにも同じ接続方法を使えます。

接続先は全体設定の `voice/engines.json` に保存します。「…」から接続先の編集・削除、接続確認と話者一覧の再読み込みができます。外部エンジンだけを使う場合、内蔵 Core のインストールは不要です。接続できない場合も入力・設定・既存音声は保持され、エンジンを起動して再試行できます。

Coreのセットアップは「今はスキップ」で後回しにできます。「今後表示しない」を選ぶと、再起動後も起動時の通知とタブ内の案内を表示しません。後からインストールする場合は、エンジンの「…」から「VOICEVOX Coreをインストール…」を開きます。案内の表示設定はBeutl標準の拡張機能設定に保存されます。

エンジンが対応する調声項目を表示します。AivisSpeech の「感情」はスタイルの感情表現の強さ、「緩急」は話す速さの緩急を調整し、両方ともプリセットに保存できます。AivisSpeechではモーラごとの編集が非対応のため「アクセント / ピッチ」は表示しません。内蔵 Core と外部接続は、タブ・TtsController・台本のプリセットで共通に利用できます。

## 台本の一括読み込み

「テキスト読み上げ」タブの上部にある「台本」を開き、台本を貼り付けるかテキストファイルを開きます。「話者: セリフ」形式と、話者名を含まない1行1セリフの形式に対応しています。全角の「：」も使えます。

「話者を読み込む」で台本内の話者を読み込み、「話者の割り当て」のComboBoxで名前ごとに共通の声のプリセットを選びます。選択したプリセットのエンジン・話者・スタイル・調声値を生成に使い、話者ごとに異なる接続先を指定できます。プリセットは「テキスト読み上げ」タブで保存し、台本側の「プリセットを再読み込み」で一覧を更新できます。

本文の確認・修正は「台本の入力」で行います。生成には入力欄の最新の内容を使い、同じ話者名へのプリセットの割り当ては保持されます。話者名を変更した場合は「話者を読み込む」で割り当てを更新できます。未割り当ての話者があっても入力を失わず、プリセットを選んで再実行できます。

開始位置・セリフ間の間隔・先頭レイヤーを指定し、「一括生成・配置」を押します。同一レイヤーに順番に配置するか、話者の登場順にレイヤーを分けられます。各セリフの開始位置は実際の音声の長さと指定した間隔から決まります。

生成した要素はまとめて Undo/Redo できます。途中の失敗・中止・配置先の重なりやロックがある場合は、一部だけを残さず配置を取り消します。台本と割り当てはタブに残り、タブの保存・復元にも対応しています。生成後の音声は各要素の `TtsController` で調整・再生成できます。

## 声のプリセット

「テキスト読み上げ」タブで本文を入力し、話者・スタイルを選んで、下部の「試聴」「追加」を使います。細かい設定は「調声」、発音ごとの調整は「アクセント / ピッチ」から開きます。

プリセットには話者・スタイル、話速、音高、抑揚、音量、前後無音を保存できます。一覧から選んで「適用」で復元します。右の「…」メニューから保存・更新・複製・改名・削除と、保存値との差分の確認を行います。

プリセットはすべて Beutl のホームディレクトリ内の `voice/presets.json` に保存し、どのプロジェクトでも共通で利用できます。未保存のプロジェクトやシーンでもプリセットを保存できます。

プリセット・接続先・話者は表示名ではなく ID で識別します。同じ話者名やスタイル番号が異なるエンジンにあっても混同しません。保存された接続先が見つからない場合は、そのプリセットを適用して「接続先を編集…」からURLを設定すると、元のIDを保って復元できます。「接続先を追加…」では同じURLでも新しいIDになるため、接続先・話者を選び直してプリセットを更新してください。接続先に保存された声がない場合も、話者を選び直してください。

生成した読み上げ要素には、本文・話者・調声値・最終 AudioQuery とプリセットの識別情報を保存します。プリセットを更新・削除しても既存の音声と生成時設定は変わりません。

タブは新しい読み上げ要素の作成に使います。「追加」はタイムラインの選択状態にかかわらず新しい要素を作成し、追加した音声と設定をまとめて Undo/Redo できます。

既存の音声を変更するには、要素の `TtsController` を開きます。本文や話者・スタイルを変更し、「調声」で話速・音高・抑揚・音量・前後無音を調整できます。「アクセント / ピッチ」の「テキストを解析」で発音ごとの編集ができ、「再生成」で編集内容を音声に反映します。これらの編集UIはタブと共通です。「声のプリセット」を選んで「適用」した後、さらに細かく調整することもできます。

再生成前の設定とアクセント編集も要素内に保存され、再度開いて編集を続けられます。編集内容は Undo/Redo に対応し、スライダーのドラッグは1操作として戻せます。「生成時の設定」には前回の生成に使った値を表示します。適用済みのプリセットは一覧のプリセットを更新・削除しても勝手には変わりません。

再生成はその要素の音声と生成時設定をまとめて更新し、配置・長さ・トリム・エフェクトを保持します。プリセットの適用と音声の再生成はそれぞれ Undo/Redo できます。本文と声が同じ場合は手編集したアクセントを引き継ぎ、本文や声を変えた場合は解析し直します。生成時設定がない古い要素は、話者を選ぶかプリセットを適用すると再生成できます。

## 開発時の検証

```sh
dotnet test tests/Beutl.Extensions.Voice.Tests -c Release
```

`VOICE_TEST_CAPTURES` に出力先を指定すると、台本読み込み、調声や TtsController の設定を展開した Headless の画面画像を保存します。`VOICEVOX_TEST_HOME` に Core・辞書・モデルを導入済みのディレクトリを指定すると、実音声の生成・再生成・複数話者の一括配置・設定の保持・Undo/Redo も検証します。指定しない場合、実音声テストだけをスキップします。

`VOICE_HTTP_VOICEVOX_URL`、`VOICE_HTTP_AIVIS_URL`、`VOICE_HTTP_SHAREVOX_URL` に起動済みエンジンのURLを指定すると、それぞれの実音声で接続・生成・再生成・台本配置を検証します。未指定のエンジンの実機テストはスキップし、HTTPの互換性・切り替え・通信失敗・UIの回帰テストはローカルのテストサーバーで実行します。
